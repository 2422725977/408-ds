# 408 数据结构 · 手写实现练习

考研 408 的数据结构**初试是笔试、要手写代码**，看懂 ≠ 写得出。
这个仓库的唯一目的：把每个数据结构**从零实现一遍**，写注释、标复杂度、留错题。

## 为什么建这个仓库

| 用处 | 说明 |
|---|---|
| 手写训练 | 每章算法自己从零写，不看答案；写完再对王道/教材解析 |
| 复杂度肌肉记忆 | 每个函数顶上标 时间/空间复杂度，写到能背出来 |
| 错题与易错点 | `notes/` 里只记卡住的地方，考前翻这个就够 |
| 复试材料 | 跨考时，"持续提交的代码仓库"比口头说"我在准备考研"有力 |
| 机试准备 | 部分院校复试有 C/C++ 上机，这里是练手场 |
| 贡献记录 | 每次 commit 都是"今天动过"的证据 |

## 目录结构


## 章节进度

- [ ] 第 1 章 绪论（时间/空间复杂度分析）

- [ ] 第 3 章 栈、队列和数组（顺序栈、链栈、循环队列、双端队列、矩阵压缩存储）

## 约定

- 文件命名：`序号-算法名.c`，例如 `linearlist/01-顺序表基本操作.c`
- 每个文件顶部写一行思路，每个函数顶部标 **时间/空间复杂度**
- `main` 里放 2~3 组用例，直接打印结果（方便自查）
- 不追求一次写对：**卡住的地方写进 `notes/`，这才是这个仓库最值钱的部分**

## 编译运行

```bash
make run f=linearlist/01-顺序表基本操作.c
```
